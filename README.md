# ChatApp

A real-time chat application built using HTML, CSS, JavaScript, and Socket.io for seamless communication.  
**Caution:** To run this app, set it up in your VS Code and start the backend server by running the command `node server.js`. The app will work only when the server is running.

## Setup Instructions

```bash
git clone https://github.com/Anujmishra2005/ChatApp.git
npm install
node server.js
